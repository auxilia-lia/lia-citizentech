# Lia: distância de Levenshtein com programação dinâmica
Antigolpe (endereços que imitam os oficiais) e busca tolerante a erro (pedidos falados com erro).
Para executar: abra `lia_levenshtein.ipynb` com a pasta `dados/` ao lado e rode todas as células em ordem.
Não precisa instalar nada: só usa a biblioteca padrão do Python 3.
Dados: `dominios_oficiais.csv` (públicos) e `jeitos_de_pedir.csv` (simulados pela equipe).
